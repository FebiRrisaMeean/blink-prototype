# Blink — интерактивный прототип

Веб-прототип карты, друзей, чатов, маркета и профиля

В маркете доступны четыре подраздела, карточки товаров, коллекция, демонстрационные покупки, выбор получателя подарка и демонстрационное пополнение баланса

В профиле доступны редактирование, выбор пола, даты рождения и стиля пина, чекины, обложка, раскрытие фото, просмотры и три вкладки старсов

Данные демонстрации сохраняются в браузере каждого посетителя. Реальные платежи, сообщения другим пользователям и отправка фото на сервер не подключены

## Локальный запуск

Требуется Node.js 24 или новее

```sh
npm ci
npm run build
npm start
```

Открыть http://127.0.0.1:4173/

## Проверки и публикация

```sh
npm test
npm run build:pages
npm run preview:pages
```

Проверочный адрес с путём репозитория: http://127.0.0.1:4187/blink-prototype/

GitHub Actions проверяет изменения и публикует ветку main через GitHub Pages. В настройках репозитория Pages → Source должен быть выбран GitHub Actions

В публикацию входят только runtime-файлы из dist. Изображения, шрифты и рабочие CSS хранятся в репозитории, JavaScript и стили Figma генерируются при сборке

## Ограничения

Карта использует статичную подложку, анимационные хвосты — статичные кадры. Отдельные переписки и настройки аккаунта не реализованы. Мобильный экран 390 × 844 масштабируется под доступное окно
